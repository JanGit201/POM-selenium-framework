# Selenium POM Automation Framework

A clean, scalable automation framework built for web application testing using Java, Selenium WebDriver, and TestNG.

## Features
- **Page Object Model (POM):** Separates test logic from page locators for better maintainability.
- **Maven:** Manages dependencies and build lifecycle.
- **TestNG:** Used for test suite execution and reporting.
  
## Prerequisites
* **Java:** JDK 8 or higher
* **Build Tool:** Maven 3.x
* **IDE:** Eclipse or IntelliJ IDEA
  
## How to run this project
1. Clone this repository to your local machine.
2. Ensure you have [Maven](https://maven.apache.org/) installed.
3. Open a terminal in the project folder and run:
   ```bash
   mvn clean test
